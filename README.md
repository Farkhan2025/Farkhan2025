### Food Ordering Backend

> A production-structured Spring Boot REST API for managing a food ordering system — built with a focus on clean layered architecture and reliable data operations.

<br/>

| Layer | Technology |
|---|---|
| Framework | Spring Boot |
| API Design | RESTful (CRUD) |
| Data Access | Spring Data JPA |
| Database | MySQL |
| Architecture | Controller → Service → Repository |
| Testing | Postman |

<br/>

**What this project demonstrates**
- Separation of concerns via layered architecture
- Entity management with Spring Data JPA and MySQL
- Clean RESTful endpoint design
- Real-world backend project structure
